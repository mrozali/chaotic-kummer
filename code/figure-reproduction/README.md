# Figure and table reproduction

This file maps every figure and table of the Letter (`paper/chaotic-kummer-v1.tex`, with the Supplemental Material `paper/chaotic-kummer-SM.tex`) to the command that regenerates or checks it, and lists quick checks of the statements in the text. The last section lists what no script checks. Statuses use the terms of the Agentic Publication Protocol.

**Conventions.** Commands run from the repository root with the interpreter set up in `environment/README.md`, for example `.venv/bin/python code/figure-reproduction/fig02_gap_ratios.py`. Every script prints a short report that ends with `RESULT: PASS` or `RESULT: FAIL`. Scripts write to `code/figure-reproduction/generated/`, and the pipeline modules cache the group tables of the point group in `code/kummer/_cache/`. Neither is committed. A figure script writes its PDF and PNG under the name of the Letter's figure file and compares the new PDF with the one in `paper/`, rendered at 100 dpi with `pdftoppm`. It passes if at most 0.1% of the pixels differ by more than 16/255 in a color channel. Without `pdftoppm` the comparison is skipped, and the script says so before `RESULT: PASS`. A check script that runs a pipeline module does so in a sandbox under `generated/<name>/`, so the stored records in `data/r2_out/` are never overwritten.

`./verify.sh` at the repository root runs the scripts marked quick below in about 3 minutes and under 1 GB of memory. `./verify.sh full` adds those marked full, about 30 minutes in all with up to 10 GB of memory. Times and memory are for the tested machine, a 14-core workstation (`environment/README.md`).

## Heavy computations

**$E=7$ on a workstation.** `.venv/bin/python code/figure-reproduction/check_lean_probe_E7.py` rebuilds the four sub-blocks of the reference direction at $E=7$ with the lean matrix-free probe and compares them with the stored record, which came from a different implementation. On the tested machine it takes 10 minutes on 14 cores and 9.4 GB of memory. With a direction `qrand101` to `qrand120` as argument it rebuilds that direction instead.

**$E=6$, truncated Hamiltonian.** `check_hidden_z2_truncated.py` takes any of `qrand101` to `qrand120`. Each run takes about 6 minutes on 4 cores and 5.4 GB.

**$E=8$ and the singlet through $E=8$** are `blocked-heavy-compute` on a workstation. The job scripts of the original cluster runs are in `code/cluster/`, with their resources. `data/README.md` lists what each run produced. In short:
- reference direction at $E=8$: `r2g_generic_probe_mf.py qgen 8` took 34 h and 233 GB. The lean probe `r2g_generic_probe_mf_lean.py <direction> 8 --irreps=<r>` needs about 44 GB for each of the four characters. On 32 cores the recorded runs took 33 to 82 minutes per character, 41 minutes in the median.
- hidden $\mathbb Z_2$ at $E=8$: `r2g_hidden_firstorder.py 8` took 4.3 h on 32 cores and 78 GB.
- reference direction through $E=7$ with the truncated Hamiltonian: `r2g_generic_sweep.py qgen 7` and `r2g_first_order_from_sweep.py qgen 7`, 256 GB requested, about two days in all.
- singlet: `r2c_fir_run.py 8 prim` with 250 GB requested, then `r2c_singlet_firstorder_L8.py` (400 s).

The stored outputs of these runs are checked by `check_paper_numbers.py`, and tied to the workstation checks in three ways: the lean probe is the code that `check_first_order_rebuild.py` runs at $E\le6$, one $E=8$ sub-block of the reference direction was computed by both implementations with the same result, and the union of the two $E=8$ eigenspaces equals the unresolved sub-block of the earlier record. At $E=7$ the truncated-Hamiltonian run behind the table and the matrix-free probe give identical sub-blocks (also in section (A)).

**The unfolding at $E=8$.** The staircase fit of degree 61 on the eigenspace of 6137 levels is close to the limit of double precision. On another linear-algebra library its unfolded levels change by up to 0.02 levels, which changes $\Sigma^2(L)$ at $E=8$ in the third decimal (0.896 on the Mac, 0.895 on Linux, at $L=10$). A fit in a numerically stable orthogonal basis gives 0.895. The Letter quotes no value of $\Sigma^2$ that this affects. The same sensitivity accounts for the few differing pixels of Fig. 3, which lie on the $E=8$ curve of $\Sigma^2(L)$.

## What no script checks

- The analytic statements: the first-order matrix and its factorization (`eq:Mc-chiral`), the rank bound (`eq:rankbound`) and its saturation argument at the odd levels, the symmetry class (Supplemental Material Sec. S3), the sector structure of the Kummer point (Sec. S1) and the exact marginality of the deformations (Sec. S2). The code implements these constructions, and the checks above test their numerical consequences, not the derivations.
- The reference values of the gap ratio, $0.5307$ (GOE), $0.5996$ (GUE), $0.3863$ (Poisson) and $0.423$ (two equal GOE spectra), which the Letter takes from the cited literature. The chiral GOE samples of `check_null_sigma.py` have means within $0.1\,\sigma$ of $0.5307$.
- The computations that need a cluster (above). Their stored outputs are checked, the runs are not repeated.
- The statement that these are, to the authors' knowledge, the first two-dimensional CFTs with this property.
